# あいことばダンジョン

～合言葉の数だけ ダンジョンが ある、ブラウザの ローグライク～
企画・実装 Claude ／ YouTube「AIでつくってためそ」

エピソード1　Ver 1.70（エピソード1は 1.xx、次の エピソード2「ブルーアースの核」は 2.xx）

ブラウザで遊ぶ ローグライク（不思議なダンジョン系）です。合言葉が同じなら、だれでも 同じダンジョンを 冒険できます。

## 遊ぶ

公開ページ：https://ai-tsukuttetameso.github.io/tsukutte-tameso-aikotoba-dungeon/

ビルドは いりません。`index.html` をブラウザで開けば そのまま遊べます（`file://` でも動きます）。HTML・CSS・JavaScript だけで動き、外部ライブラリは つかっていません（文字の 書体だけ Google Fonts から 読みこみます）。絵・音楽・効果音は すべて コードで その場で 作っている オリジナルです。

## 記録の 保存

- 記録（冒険者データ・職業レベル・まもの図鑑・クリアの記録・再開の階・セーブ）は、遊んでいる ブラウザの 中（localStorage）だけに のこります。サーバーには 送りません
- ブラウザの データを けすと 記録も きえます。タイトルの「冒険者データ」→「記録コードを 書き出す」で 記録を 文字列に して のこせます。ほかの 端末で「読みこむ」と 同じ 記録で 遊べます
- 記録の 名前は「aikotoba_」で はじまります

## あそびかた

- 矢印キー・WASD で移動、Q E Z C で ななめ、Shift＋方向で ダッシュ
- 敵に向かって進むか、F キー（「こうげき」ボタン）で こうげき。やり・つえ・むち・ブーメランは 遠くまで とどきます
- 階段の上で Enter で 下の階へ
- I：もちもの一覧／B：袋の中身一覧／M：わざ一覧／Shift＋数字：わざを すぐ使う
- スマホは 画面下の ボタンか、画面の行きたい方向を タップ
- 合言葉を入れると、同じ合言葉の人は みんな同じダンジョン（地図・道具・敵の配置）になります
- 合言葉のときは 深さを 地下10・20・30・50・100階から えらべます。深いほど 新しい敵と レアな道具が 出ます
- 合言葉によっては「おたからダンジョン」（レアな道具と お金が 出やすい）になります

## 読みこみ順の ルール

モジュールの仕組み（import）を使わず、ふつうの `<script>` を順番に読みこんでいます。`file://` で開いても動くようにするためです。

- 前のファイルで作った `const` や `function` を、あとのファイルで使えます
- 読みこんだ瞬間に動く処理（起動など）は `main.js` に まとめています
- 新しいファイルを足すときは `index.html` の `<script>` の並びにも 追加してください

## よく さわる場所

- 敵を足す：`data/monsters.js` の `MON` と `FLOOR_MON`（10階まで）・`DEEP_MON`（深い階）

- お店の品ぞろえ：`data/shop.js` の `SHOP_STOCK`（`*` はいくつでも、`?` はときどき）
- わざ：`game/skills.js` の `SKILLS`

## 職業

- せんし：HPと こうげきが 高い（2回斬り・回転斬り・3回斬り）
- シーフ：敵の こうげきを 4回に 1回 よける（ぬすむ・わなさがし・けむりだま）
- かじや：そうびを その場で ＋1。お店の 合成が 半額（きたえる・かたくする）
- まほうつかい：MPが 多く、まほうが 1.3倍（ファイア・ヒール・ブリザド・サンダー）
- どうぐつかい：回復の 道具と 投げる ダメージが 1.5倍。ひろった物の 正体が わかる（みやぶる）
- 上位職（2つ きわめると ひらく。基本5つの 組み合わせ 10通り）：両方の とくいと わざ ＋ 上位職だけの とくい ＋ とっておきの わざ
- 最上位職（上位職を 3つか 4つ きわめると ひらく。3つだけ。TOP_JOBS）：ゆうしゃ（まほうけんし＋ぶきマスター＋ソードダンサー＋かりゅうど。ふつうの こうげき1.25倍・最大HP＋15・ひかりのつるぎ）／だいけんじゃ（けんじゃ＋れんきんじゅつし＋げんじゅつし＋あきんど。わざの MP半分・てんちのいかり）／かげのおう（にんじゃ＋からくりし＋げんじゅつし。3回に1回 分身が こうげきを うける・かげぶんしん）

  - にんじゃ（シーフ＋どうぐつかい）：よける 40%・はんげき／かげぬい
  - けんじゃ（まほうつかい＋どうぐつかい）：3ターンごとに MP＋1／メテオ
  - ぶきマスター（かじや＋せんし）：かいしんの いちげき／ひっさつ
  - ソードダンサー（せんし＋シーフ）：ときどき 2回こうげき／つるぎのまい
  - かりゅうど（せんし＋どうぐつかい）：矢と 投げる 2倍／ねらいうち
  - からくりし（シーフ＋かじや）：わなが 見えて かからない／からくりばくだん
  - げんじゅつし（シーフ＋まほうつかい）：うける ダメージ 4分の3／まどわし

## 敵（100しゅるい）

もとの 15しゅるいに、85しゅるいを 足した（data/monsters_more.js の MORE_MON）。足した 敵は「同じ 強さの なかま」として、出現表で えらばれた 敵と 入れかわって 出る（widenMon）。
- 入れかえは 合言葉と 場所から きめるので、同じ 合言葉なら 同じ 敵。地図・道具の 並びは 前と かわらない
- 新しい とくちょう：regen（毎ターン HPが 5% 回復）・hunger（なぐられると おなか −5）・mpdrain（なぐられると MP −2）
- ロボ特効・でかこわ特効などは「なかま」で きまる（robo3 なども ロボ）

## 階の しかけ・ぬし・かくし合言葉

js/world/floorplus.js。どれも 合言葉と 階から きめるので、同じ 合言葉なら 同じ。ダンジョンを つくる 乱数は つかわないので、地図・道具は 前と 同じ（おかねの階の お金だけ 足される）。
- 階の しかけ（3階から、3階に 1回くらい）：くらやみ（2マスしか 見えない）・こおり（止まれずに すべる）・はらぺこ（おなか 2倍）・おかね（お金 2倍）・まりょく（わざの MP 半分）・つわもの（敵が 強いが けいけんち 2倍）
- ぬし：10・20・30…階（さいごの 階を のぞく）に、その階で いちばん 強い なかまの「ぬし」。たおすまで 階段は ふういん。たおすと そうびと お金を 落とす
- かくし合言葉：SECRETS に ある 合言葉を 入れると とくべつな ダンジョンに なる（中身は ファイルを 見てね）

## BGM

js/audio/bgm.js。その場で 作る ピコピコ音で、ぜんぶ オリジナル（17曲）。タイトルは 3曲を ひらく たびに 順番に。たんけん中は 深さで かわる（1〜29階・30〜59階・60階より 深く）。しかけの 階・ぬしの 階は それぞれの 曲。敵に かこまれた とき・お店・さいごの 階は いままでどおり。

## 階の ワープ（もぐる・浮上する）

js/game/warp.js。いっきに 階を 動ける おふだと わざ。おふだは 合言葉と 階で きまる 場所に たまに おちている（地図・ほかの 道具は かわらない）。
- おふだ：くだりのおふだ（1階 もぐる）・のぼりのおふだ（1階 浮上）・おおぞこのおふだ（3階 もぐる）・そらとびのおふだ（3階 浮上）。名前は さいしょから わかる
- わざ：うかびの術（2階 浮上。シーフ Lv6・まほうつかい Lv7）・もぐりの術（2階 もぐる。にんじゃ Lv7）・ちていへの とびら（4階 もぐる。けんじゃ Lv9）
- ぬしが いる 階では 下へは 行けない。さいごの 階より 下・1階より 上には 行けない

## オープニング（デモプレイ）と エンディング

- js/ui/attract.js：タイトルで 25秒 何も しないと、あらすじが 出て、そのあと せんしが 自動で 冒険する デモプレイが 45秒 流れる。キーか 画面を おすと タイトルに もどる。デモの あいだは 記録・コレクション・セーブに 何も 書きこまない
- js/ui/ending.js：でかこわの王を たおすと、クリアの 記録を のこしてから エンディング（物語の しめくくり・この 冒険の 記録・出会った まもの・スタッフ・エピソード2の 予告）が 流れる。「とばす」で とばせる。曲は「たびの おわりに」
- コレクションの「ムービー」タブで オープニングを いつでも 見なおせる。エンディングは 地下100階の ダンジョンを さいごまで クリアすると 見られる（さいごの 100階クリアの 記録で 流れる）
- js/game/shinboss.js：地下100階の ダンジョンでは、でかこわの王を たおすと「でかこわの王・真の姿」に 変身して 2回戦になる（体力1.5倍・こうげき1.25倍・4ターンに1回 はなれていても とどく「やみの いき」・体力が 半分を きると いかって こうげきが 上がる）。図鑑の 数は ふえない
- js/game/nimotsu.js（v1.63）：にもつの わざ。「ふくろぬい」（どうぐつかい4・シーフ6）＝いちばん 小さい しまう袋の 入る数＋1、「にもつもち」（あきんど2・かじや6・せんし8）＝袋 ぜんぶ＋1、合わせ技「よじげんぶくろ」＝袋 ぜんぶ＋2。袋は 1つ 12こまで（もちものの わくは 12の まま）。にもつ（もちもの＋袋の 中身）が 12こを こえると、こえた 数 × ターン が 150 たまるごとに おなか −1。かじやの「袋の中身を うる」でも まとめて えらんで うれる。おもくても ふつうの へりかたに なる 防具の 特性「かるがる」と わざ「かるがるせおい」（あきんど5・シーフ9、100ターン）もある
- 合成（v1.65）：2つの 特性を あわせて わく（多い ほうの わく）に 入りきらない ときは、のこす 特性を えらぶ 画面に なる。えらばなかった 特性は なくなる
- js/ui/traitpop.js（v1.66）：もちものの 装備に「特性」ボタン。おすと 別の 小窓で 特性の 名前・せつめい・わくの あきが 見られる（Esc か とじるで もどる）
- v1.67：袋の 中の 装備にも「特性」ボタン。かじやの「かう」は ジャンル（武器・防具・食べ物・草・くすり・おふだ・まきもの・杖・その他）で しぼって 見られる
- v1.68：こおりの階に 入ると「ななめに 歩くと すべらない」の ヒントが 出る（その階で はじめて すべった ときにも 1回）
- v1.69：つかいやすさの 見なおし。かじやで そうび中の物・中身入りの 袋は 2回 おして うる／おなかの よこに「おもい＋n」「かるがる」／画面の 上に 効いている わざと のこりターン／タイトルに「あそびかた」（js/ui/howto.js）／冒険中も「図鑑」ボタンか Kキーで コレクションを 見られる（ムービーは のぞく）／セーブ画面で「その階で 手に入れた物は 入らない」を 明記／属性で「こうかは ばつぐん」「あまり きいていない」に なると、その まものの 弱点・ききにくい 属性が すぐ 図鑑に のる／タイトルの デモまで 50秒（マウスを うごかすと 数えなおす）／スマホ横向きで 地図が 上の 表示に かさならないよう 修正

## わざ・合わせ技・特性（v1.57 で ふやした）

- わざ：ぜんぶで 62（職業の わざ 49 ＋ 合わせ技 13）。どの 職業が どの わざを おぼえるかは js/data/jobs.js と js/game/skills_more.js の SKILL_JOBS
- 合わせ技：2つの わざを 両方 使えるように なると「発明」して 使える（ほかの 職業から ひきついだ わざでも よい）。例：ファイア＋ブリザド＝スチームボム、回転斬り＋3回斬り＝たつまきぎり、ぬすむ＋けむりだま＝かいとうの わざ。コレクションでは まだの 合わせ技も 材料が わかる
- 毒（どくばり）・こんらん・きあいため・てっぺき・みきり など、あたらしい 状態も ふえた
- 特性：ぜんぶで 31。武器に 雷の刃・かいしん・まりょく吸収・ひるませ・れんげき・こがねぎり・ぬし特効、防具に わなよけ・回復じょうず・ふんばり・たからみ・せつやく を ふやした。武器の 特性も ふやした 中から 出る（地図・道具の 場所は かわらない）

## 裏モード

js/game/difficulty.js。地下100階の ダンジョンを 1回 クリアすると、タイトルの「あそぶ」に 敵の 強さを えらぶ らんが 出る。イージー（HP×0.6・こうげき×0.7）／ノーマル（いつもどおり）／ハード（HP×1.5・こうげき×1.3・けいけんち×1.3）／ベリーハード（HP×2.2・こうげき×1.7・けいけんち×1.6）。かわるのは 敵の 強さだけで、地図・道具は 同じ。クリアの記録と シェア文に 強さが つき、順位は 強さごとに わかれる。

## 称号と ごほうび

js/game/titles.js。やりこむと 称号（26こ）が 手に入る。コレクションの「称号」タブで 1つ えらぶと、タイトルと クリアの シェア文に つく。コレクションを うめた わりあい（10・25・50・75・100%）で、主人公の 色ちがいが ふえる（heroLook）。

## しんか

＋100まで きたえた そうびは、AIかじやの「しんか」で 上の そうびに かえられる（1000G。かじやは 半額）。しんか先は 2〜3つから えらぶ（data/items_evo.js の EVO_TO）。
- 武器は 種類ごと（けん・やり・つえ・むち・ブーメラン）、ぼうぐは 場所ごと（たて・あたま・うで・あし）に しんか先が きまる
- ＋は 100 へって のこる（＋130 → ＋30）。特性は そのまま、特性の わくが 1つ ふえ、しんか先に よっては 特性が 1つ つく
- しんか先の そうびは 床や お店には 出ない。コレクションの そうびに「？？？」で ならぶ

## コレクション

タイトルの「コレクション」から 見られる。遊んだ 回数に おうじて すこしずつ ひらく（localStorage の aikotoba_prog）。
- まもの：出会うと 名前と 絵 → 1体 たおすと つよさ → 3体で 弱点と とくちょう → 10体で せつめい
- 道具：手に入れると 名前 → 使うと せつめい → 5回 使うと ★
- そうび：手に入れると 名前 → そうびすると せつめい
- 特性：その 特性が ついた そうびを 手に入れると ひらく
- 職業：なれるように なると ひらく。わざ：おぼえると 名前、使うと せつめい
- おと：ゲームの 中で いちど 聞いた BGM（5曲）と 効果音（42）が ひらき、タップで 聞ける（音が オフでも 聞ける。BGMは audio/bgm.js の bgmPreview）
- 記録は ターンの おわりに まとめて 書く（progFlush）

## 職業の つながり（タイトル）

タイトルの 職業えらびは トーナメント表の 形。きほん（5）→ 上位（10）→ 最上位（3）を 線で つなぎ、えらんだ 職業の「もと」と「さき」は 金色に なる（ui/jobs.js の drawJobWires）。

## 記録ファイル

「冒険者データ」→「記録ファイルを ほぞんする」で、記録を JSON ファイル（aikotoba-kiroku-日付.json）として 端末に のこせる。「記録ファイルを 読みこむ」で もとに もどる（js/ui/hero.js の saveTextFile・codeFromFile）。
- ファイルの 中身は 説明・ほぞんした 日時・記録コード（code）。記録コードだけを 書いた テキストファイルも 読める
- 読みこむ ときは「ほんとうに 読みこむ？」を 1回 はさむ

## 冒険者データ（ひきつぎ）
- 「やめる」で 中断した 冒険が のこったまま 新しい 冒険を はじめると、その 冒険の 装備・お金・レベルも 冒険者データに のこる（bankSuspended）

冒険が おわると（クリア・力つきた）、レベル・お金・手に入れた 装備が 冒険者データに のこる。力つきると お金は 半分（game/hero.js の HERO_DEAD_GOLD）。つぎの 冒険では レベルと お金は そのまま、そうびしていた 装備は そうびした まま、ほかの 装備は 強い順に 4こ もちものへ。のこりは「そうこ」（30こまで）。タイトルの「冒険者データ」で 見られる・リセットできる。
とちゅうで「やめる」で もどったときは 冒険が 中断（つづきから）なので まだ のこさない。

## 10階ごとの 再開
- 合言葉・今日のダンジョン・「同じ合言葉で もう一度」で はじめるとき、とどいた 階が あれば「地下1階から／10階から／20階から…」を えらぶ 画面が 出る（js/ui/start.js の pickStart）

- 冒険者データの レベルが 5以上なら、レベルと 同じ 階まで（5階きざみ）いきなり はじめられる。「−」「＋」で 5階ずつ えらぶ（js/ui/start.js の levelMaxFloor・levelStartFloor）。合言葉・今日のダンジョンは ボスの 階より 手前まで。新しい ダンジョン（はじめる）は、えらんだ 階より 深い ダンジョンを つくる（地下15階から → 地下20階まで。randomDepthFor）。クリアの記録には「○階から」と のこる

合言葉の ダンジョンで 地下10・20・30…階に とどくと、つぎから その階から はじめられる（タイトルの 合言葉の 行の「地下○階から」、力つきた画面の「地下○階から 再開」）。地図は 1階から 来たときと 同じ。

## 武器の なかま・金策

剣（どう・はがね・ほのお・こおり・いかずち・ひかり）、やり（てつ・はがね・ほのお・りゅう）、つえ（まほう・ルーン・ほのお・けんじゃ）、むち（かわ・いばら・くさり）、ブーメラン（ふつう・はがね・ほし）。深い階ほど 強い物が 出る。合成は しまう袋の 中の 装備とも できる。
金策：ルビー・サファイア・エメラルド・ダイヤモンド・きんかい（使っても なくならず、お店で 高く 売れる）、きんのたまご（使うと お金）。床や 敵（つよい こたいは よく 落とす）から 出る。

## お弁当

だけ弁当の ほかに、おにぎり・のり弁当・からあげ弁当（HPも）・さけ弁当（MPも）・カレー弁当（この階の あいだ こうげき＋2）・まくのうち弁当・とくせい弁当（レア・ぜんぶ回復）。床に 1階 1〜2こ、お店にも ならぶ。

## しまう袋
- 袋の 中の 道具を 使っても 袋は ひらいたまま（つづけて 使える）

しまう袋の 中に しまう袋は 入れられない。

## 敵の つよい こたい

2階から下で だいたい 15ぴきに 1ぴき。色ちがいで ピンクに 光り、頭に 王冠。名前は「つよい○○」。HP2倍・こうげき1.35倍・けいけんち3倍・かならず 何か 落とす。合言葉と 場所で きまるので 同じ合言葉なら 同じ。

## うごき

主人公は 歩く 向きを むく（左右は 反転、上は うしろ すがた）。こうげきすると 相手の ほうへ ふみこみ、きりつけの 光が 出る。敵も こうげきの とき ふみこむ（gfx/render.js の attackAnim・monAnim）。

職業を ふやすときは data/jobs.js に 1行、見た目は gfx/sprites_jobs.js の JOB_LOOK に 1行 足す。

## わざの なかま分け
- わざは「こうげき・まほう・回復・にげる・べんり・そうび」に 分かれる（js/ui/skillbar.js の SKILL_TABS・SKILL_GROUP。ここに ない わざは まほう／こうげき に 入る）
- おぼえた わざが 5つ以上に なると、わざバーに タブが 出る。えらんだ タブは この端末に のこる
- わざ一覧（M）で ☆を おすと「★よく使う」タブに 入る
- 番号キー（わざ一覧）と Shift＋番号（いつでも）は、いま 出ている タブの 中の 順番。わざ一覧では Tab キーで タブを かえる

## 特性の わく
- 装備の 特性は ふつう 3つまで。わくは 最大 6つまで ふやせる（js/game/items.js の TRAIT_SLOT_BASE・TRAIT_SLOT_MAX・traitCap）
- ふやし方は 3つ：道具「あなあけのみ」（たまに おちている・お店にも 出る）／かじやの わざ「あなあけ」（Lv7・1つの 階で 1回）／AIかじやの「わくを ふやす」（えらんだ 装備。かじやは 半額）
- のみと わざは、そうびの 中で 特性が うまっている物 → わくが 少ない物 の 順に ふやす（slotTarget）
- 合成すると わくは 多いほうを ひきつぎ、特性は わくの 数まで のこる
- AIかじやで 買うとき、いまの そうびに ない 特性は 緑色で 出る（descNewTraits）

## 防具の 特性
- たて・あたま・うで・あしの 特性は 14しゅるい。もちもの一覧の「そうび中」タブで、ついている 特性の せつめいが 見られる
- ねこよけ／トゲよけ／はらもち／はねかえし
- さいふのひも（お金を ぬすまれない・お金の わなが 効かない）／みかわし（8回に1回 よける）／じわじわ回復（3ターンごとに HP＋1）／まりょく回復（5ターンごとに MP＋1）
- がけっぷち（HP3わり以下で こうげき1.5倍）／まなび（けいけんち1.2倍）／きんうん（ひろう お金1.3倍）／ちずよみ（階段の 場所が わかる）／ロボよけ（ロボからの ダメージ半分）／でかこわよけ（でかこわからの ダメージ4分の3）
- 道具が 生まれるときの 乱数の 並びは かえていない（js/data/items.js の GEN_TRAITS）。あとから ふやした 特性は、べつの 乱数（js/game/items.js の trRoll・widenTraits）で 入れかえて 出すので、同じ 合言葉なら 地図・道具・敵は 前と 同じ

## そうび

武器（atk）・たて（def）・あたま（head）・うで（arm）・あし（foot）を 1つずつ つけられる。ぼうぎょは たて＋あたま＋うで＋あしの 合計。部位は data/items.js の equip で きめる。合成は 同じ 部位どうしだけ。そうび中の物は「そうびバッグ」あつかいで、もちもの（12こ）に 数えない。はずすと もちものに もどるので、もちものが いっぱいの ときは はずせない（入れかえは そのまま できる）。お店では もちものが いっぱいでも、しまう袋に 空きが あれば 袋に 入れて 買える。

## 画面の こまかさ
- タイトルの あいだは もちもの・わざ・ボタン・ログを かくして、タイトルを 大きく 出す（screens.js の setTitleMode と css の .titlemode）

ゲーム画面は キャンバスを 2倍（gfx/render.js の GZ）で かき、ドット絵は smooth()（Scale2x）で なめらかにした 2倍の 絵を はる。

## セーブ

- 階に 入るたびに 自動で この端末に セーブされます。タイトルの「つづきから」で その階の はじめから 再開できます
- 「セーブ」ボタンで「ふっかつの合言葉」が 出ます。タイトルの「ふっかつの合言葉」に はりつけると、ほかの端末でも 再開できます
- 力つきたり クリアしたりすると、この端末の セーブは 消えます

## クリアの記録と シェア

- クリアすると この端末（ブラウザ）に記録が のこり、タイトルの「クリアの記録」で 合言葉ごとの 順位が 見られます
- クリア画面で シェア文を コピーしたり、Xの 投稿画面を ひらけます（投稿は 自分で おこないます）
- 公開先の URL が きまったら `js/ui/records.js` の `SHARE_URL` に 入れると シェア文に つきます

## 名前を かえるとき

`js/core/util.js` の `GAME_NAME` と、`index.html` の `<title>` を かえます。
